# Aprendiendo Python desde cero

Repositorio personal donde voy guardando mis apuntes, ejercicios y prácticas mientras aprendo Python desde cero.

La idea es ir construyendo este repositorio poco a poco a medida que avanzo en el aprendizaje.

## Contenido

### Tipos de datos

* Datos simples
* Datos compuestos
* Variables
* Operadores
* Condicionales
* Listas y diccionarios

### Próximamente

* Bucles
* Funciones
* Excepciones
* Módulos
* Programación orientada a objetos
* Proyectos prácticos

## Objetivo

Aprender Python desde las bases, entender cómo funciona el lenguaje y conseguir desarrollar pequeños programas y proyectos por mi cuenta.

## Progreso

Este repositorio se irá actualizando conforme avance en mi aprendizaje.

> En construcción — aprendiendo Python paso a paso.
